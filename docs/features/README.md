# Feature docs

One file per feature/module, named after the module (not the story id) — e.g. `document-loaders.md`,
`pii-masking.md`, `tabular-column-profiling.md` — since a single doc often accumulates content across
several related stories.

Written by whichever agent completes the story that introduces or extends the feature, using the
`feature-doc-writer` skill and the fixed structure in [_TEMPLATE.md](_TEMPLATE.md). See
[.claude/rules/documentation-standards.md](../../.claude/rules/documentation-standards.md) for the full
rules.

This directory is empty of feature docs until the first story lands — that's expected for a
scaffolding-only state.
